## س1. ما البيانات التي يجب أن يحتوي عليها سجل سبب الخروج؟

- **Question Key:** `exit_reason.fields`
- **النوع:** `multi_choice`
- **مطلوب:** نعم
- **الحالة الحالية:** ظاهر وقابل للإجابة
- **التصنيف التقريري:** `field`
- **الكيان المستهدف:** `exit_reason`

### التوضيح

حدد البيانات الأساسية التي يجب أن يدعمها سبب الخروج باعتباره Master Data مرجعية تستخدم لاحقًا في العمليات والتقارير.

### الاختيارات

- `name` — اسم سبب الخروج بالعربية والإنجليزية
- `description` — وصف سبب الخروج بالعربية والإنجليزية
- `is_active` — الحالة: نشط / غير نشط
- `sort_order` — ترتيب الظهور
- `notes` — ملاحظات

### الإجابة

**الإجابة الحالية:** اسم سبب الخروج بالعربية والإنجليزية، وصف سبب الخروج بالعربية والإنجليزية، الحالة: نشط / غير نشط، ترتيب الظهور، ملاحظات

**القيمة الخام المحفوظة:**

```json
[
    "name",
    "description",
    "is_active",
    "sort_order",
    "notes"
]
```

## س5. كيف يجب التعامل مع سبب الخروج لم نعد نريد استخدامه؟

- **Question Key:** `exit_reason.retirement_policy`
- **النوع:** `single_choice`
- **مطلوب:** نعم
- **الحالة الحالية:** ظاهر وقابل للإجابة
- **التصنيف التقريري:** `lifecycle_rule`
- **الكيان المستهدف:** `exit_reason`

### التوضيح

حدد سياسة التعامل مع قيمة Master Data قد تكون مستخدمة تاريخيًا، بحيث لا يؤدي إيقاف استخدامها إلى كسر السجلات السابقة.

### الاختيارات

- `disable_only` — يتم تحويله إلى غير نشط ولا يسمح بحذفه
- `delete_if_unused_otherwise_disable` — يسمح بحذفه فقط إذا لم يتم استخدامه سابقًا، وإلا يتم تعطيله
- `soft_delete` — يسمح بالحذف المنطقي Soft Delete مع الاحتفاظ بالسجل التاريخي

### الإجابة

**الإجابة الحالية:** يتم تحويله إلى غير نشط ولا يسمح بحذفه

**القيمة الخام المحفوظة:**

```json
"disable_only"
```

### المراجعة

- **الحالة:** لا توجد مراجعة معلقة

## س6. ما أسباب الخروج المبدئية التي يجب أن يوفرها النظام؟

- **Question Key:** `exit_reason.initial_values`
- **النوع:** `multi_choice`
- **مطلوب:** نعم
- **الحالة الحالية:** ظاهر وقابل للإجابة
- **التصنيف التقريري:** `lookup_values`
- **الكيان المستهدف:** `exit_reason`

### التوضيح

حدد القيم المبدئية التي يجب إضافتها عند تهيئة النظام. هذا السؤال يخص أسباب الخروج كـMaster Data فقط، أما استخدامها داخل العمليات فيتم حسمه في الأقسام التشغيلية المناسبة.

### الاختيارات

- `sale` — بيع
- `mortality` — نفوق
- `final_exclusion` — استبعاد نهائي
- `transfer_to_another_farm` — نقل إلى مزرعة أخرى
- `internal_slaughter_consumption` — ذبح / استهلاك داخلي
- `lost` — فقد
- `other` — سبب آخر

### الإجابة

**الإجابة الحالية:** بيع، نفوق، استبعاد نهائي، نقل إلى مزرعة أخرى، ذبح / استهلاك داخلي، فقد، سبب آخر

**القيمة الخام المحفوظة:**

```json
[
    "sale",
    "mortality",
    "final_exclusion",
    "transfer_to_another_farm",
    "internal_slaughter_consumption",
    "lost",
    "other"
]
```

### المراجعة
