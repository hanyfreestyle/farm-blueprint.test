## س1. ما البيانات التي يجب أن يحتوي عليها تعريف النوع الفيزيائي للقفص؟

- **Question Key:** `cage_physical_type.fields`
- **النوع:** `multi_choice`
- **مطلوب:** نعم
- **الحالة الحالية:** ظاهر وقابل للإجابة
- **التصنيف التقريري:** `field`
- **الكيان المستهدف:** `cage_physical_type`

### التوضيح

النوع الفيزيائي يصف تصميم القفص ومقاسه وتجهيزاته، وهو منفصل عن الاستخدام التشغيلي الحالي مثل أنثى إنتاج أو فطام أو تسمين أو عزل.

### الاختيارات

- `name` — اسم النوع بالعربية والإنجليزية
- `description` — وصف النوع بالعربية والإنجليزية
- `dimensions` — الأبعاد / المقاسات
- `physical_features` — وصف التجهيزات أو الخصائص الفيزيائية
- `default_capacity` — السعة الافتراضية إن كانت مرتبطة بالتصميم
- `is_active` — الحالة: نشط / غير نشط
- `sort_order` — ترتيب الظهور
- `notes` — ملاحظات

### الإجابة

**الإجابة الحالية:** اسم النوع بالعربية والإنجليزية، وصف النوع بالعربية والإنجليزية، الأبعاد / المقاسات، وصف التجهيزات أو الخصائص الفيزيائية، السعة الافتراضية إن كانت مرتبطة بالتصميم، الحالة: نشط / غير نشط، ترتيب الظهور، ملاحظات

**القيمة الخام المحفوظة:**

```json
[
    "name",
    "description",
    "dimensions",
    "physical_features",
    "default_capacity",
    "is_active",
    "sort_order",
    "notes"
]
```

### المراجعة

## س4. كيف يجب تمثيل المواصفات الفيزيائية التي تختلف بين أنواع الأقفاص؟

- **Question Key:** `cage_physical_type.attribute_model`
- **النوع:** `single_choice`
- **مطلوب:** نعم
- **الحالة الحالية:** ظاهر وقابل للإجابة
- **التصنيف التقريري:** `architecture_rule`
- **الكيان المستهدف:** `cage_physical_type`

### التوضيح

المصدر يطرح المقاسات والتجهيزات كخصائص محتملة تستحق التسجيل. المطلوب تحديد مستوى المرونة دون افتراض قائمة مواصفات غير موجودة في المرجع.

### الاختيارات

- `fixed_core_fields_with_features_description` — حقول أساسية ثابتة مثل الأبعاد والسعة مع وصف إضافي للتجهيزات
- `flexible_key_value_attributes` — مواصفات مرنة Key/Value لكل نوع بجانب الاسم والوصف
- `name_description_only` — اسم ووصف فقط، وتبقى المواصفات التفصيلية داخل تكوين البطارية أو ملاحظات القفص

### الإجابة

**الإجابة الحالية:** اسم ووصف فقط، وتبقى المواصفات التفصيلية داخل تكوين البطارية أو ملاحظات القفص

**القيمة الخام المحفوظة:**

```json
"name_description_only"
```

## س5. كيف يجب التعامل مع نوع فيزيائي للقفص لم نعد نريد استخدامه؟

- **Question Key:** `cage_physical_type.retirement_policy`
- **النوع:** `single_choice`
- **مطلوب:** نعم
- **الحالة الحالية:** ظاهر وقابل للإجابة
- **التصنيف التقريري:** `lifecycle_rule`
- **الكيان المستهدف:** `cage_physical_type`

### التوضيح

يجب ألا يؤدي إيقاف نوع مستخدم تاريخيًا إلى كسر سجلات الأقفاص السابقة.

### الاختيارات

- `disable_only` — يتم تحويله إلى غير نشط ولا يسمح بحذفه
- `delete_if_unused_otherwise_disable` — يسمح بحذفه فقط إذا لم يستخدم سابقًا، وإلا يتم تعطيله
- `soft_delete` — يسمح بالحذف المنطقي Soft Delete مع الحفاظ على التاريخ

### الإجابة

**الإجابة الحالية:** يتم تحويله إلى غير نشط ولا يسمح بحذفه

**القيمة الخام المحفوظة:**

```json
"disable_only"
```

### المراجعة

- **الحالة:** لا توجد مراجعة معلقة
