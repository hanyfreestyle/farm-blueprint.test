## س1. ما البيانات التي يجب أن يحتوي عليها تعريف استخدام القفص؟

- **Question Key:** `cage_usage.fields`
- **النوع:** `multi_choice`
- **مطلوب:** نعم
- **الحالة الحالية:** ظاهر وقابل للإجابة
- **التصنيف التقريري:** `field`
- **الكيان المستهدف:** `cage_usage`

### التوضيح

الاستخدام التشغيلي يصف الغرض الحالي للقفص مثل أنثى إنتاج أو ذكر أو فطام أو تسمين أو حجر/عزل، وهو منفصل عن النوع الفيزيائي للقفص.

### الاختيارات

- `name` — اسم الاستخدام بالعربية والإنجليزية
- `description` — وصف الاستخدام بالعربية والإنجليزية
- `is_active` — الحالة: نشط / غير نشط
- `sort_order` — ترتيب الظهور
- `notes` — ملاحظات

### الإجابة

**الإجابة الحالية:** اسم الاستخدام بالعربية والإنجليزية، وصف الاستخدام بالعربية والإنجليزية، الحالة: نشط / غير نشط، ترتيب الظهور، ملاحظات

**القيمة الخام المحفوظة:**

```json

    "name",
    "description",
    "is_active",
    "sort_order",
    "notes"
]
```

## س5. ما العلاقة المطلوبة بين استخدام القفص والأنشطة التشغيلية الموجودة بالفعل في Master Data؟

- **Question Key:** `cage_usage.operational_activity_relation`
- **النوع:** `single_choice`
- **مطلوب:** نعم
- **الحالة الحالية:** ظاهر وقابل للإجابة
- **التصنيف التقريري:** `relationship_rule`
- **الكيان المستهدف:** `cage_usage`

### التوضيح

الأنشطة التشغيلية تستخدم على مستويات أعلى مثل العنبر والبطارية، بينما استخدام القفص أكثر تحديدًا. المطلوب منع تكرار مفهوم واحد دون داعٍ مع السماح بفصل الاستخدام عند الحاجة.

### الاختيارات

- `independent_from_operational_activity` — استخدام القفص قائمة مستقلة تمامًا عن النشاط التشغيلي
- `linked_to_one_operational_activity` — كل استخدام قفص يرتبط بنشاط تشغيلي واحد مناسب
- `optional_operational_activity_link` — الربط بالنشاط التشغيلي اختياري حسب الاستخدام

### الإجابة

**الإجابة الحالية:** الربط بالنشاط التشغيلي اختياري حسب الاستخدام

**القيمة الخام المحفوظة:**

```json
"optional_operational_activity_link"
```

### المراجعة

## س6. كيف يجب التعامل مع استخدام قفص لم نعد نريد استعماله؟

- **Question Key:** `cage_usage.retirement_policy`
- **النوع:** `single_choice`
- **مطلوب:** نعم
- **الحالة الحالية:** ظاهر وقابل للإجابة
- **التصنيف التقريري:** `lifecycle_rule`
- **الكيان المستهدف:** `cage_usage`

### التوضيح

يجب ألا يؤدي إيقاف استخدام سبق ربطه بأقفاص أو سجلات تاريخية إلى كسر التاريخ السابق.

### الاختيارات

- `disable_only` — يتم تحويله إلى غير نشط ولا يسمح بحذفه
- `delete_if_unused_otherwise_disable` — يسمح بحذفه فقط إذا لم يستخدم سابقًا، وإلا يتم تعطيله
- `soft_delete` — يسمح بالحذف المنطقي Soft Delete مع الحفاظ على التاريخ

### الإجابة

**الإجابة الحالية:** يتم تحويله إلى غير نشط ولا يسمح بحذفه

**القيمة الخام المحفوظة:**

```json
"disable_only"
```

### المراجعة

- **الحالة:** لا توجد مراجعة معلقة
